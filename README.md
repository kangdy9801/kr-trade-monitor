# 수출입·산업활동 브리핑

산업통상부 「수출입 동향」과 국가데이터처 「산업활동동향」 보도자료 **PDF 2개를 올리면** 자동으로 분석하는 정적 웹사이트입니다. 서버 없이 GitHub Pages에서 동작하며, PDF는 브라우저 안에서만 읽고 어디에도 전송하지 않습니다.

## 사용법

1. 사이트 상단 ‘보도자료 PDF 2개로 분석하기’에 두 PDF를 끌어다 놓거나 고릅니다. 예: 10월 수출입 동향 + 9월 산업활동동향
2. 두 파일의 종류와 기준월이 표시되면 **분석하기**를 누릅니다.
3. 분석 결과가 이 브라우저에 기록으로 저장되고, 직전 달 기록이 있으면 ‘지난 자료 대비’가 자동으로 채워집니다.

## 기록 저장 방식

- **기본 기록** `assets/seed.js`: 저장소에 올라가 있어 누구에게나 보입니다. 지금은 2026년 9월·10월 수출입(8월·9월 산업활동) 두 달이 들어 있습니다.
- **내 기록**: 사이트에서 올린 PDF 분석 결과. 그 브라우저에만 저장됩니다.

다른 기기나 방문자에게도 새 달 기록을 보이게 하려면:

1. 사이트에서 PDF를 올려 분석합니다.
2. ‘기록 관리 → seed.js 만들기’로 파일을 받습니다 (기본 기록 + 내 기록이 모두 들어 있음).
3. 받은 파일로 저장소의 `assets/seed.js`를 덮어쓰고 커밋·푸시합니다.

‘내 기록 내보내기 / 기록 가져오기’로 브라우저 간에 기록을 옮길 수도 있습니다.

## 파일 구조

```
index.html          화면 구조
assets/parser.js    PDF → 숫자 (pdf.js로 표·문장 읽기). 브라우저와 Node 공용
assets/analyze.js   숫자 → 판정·분해·체크리스트·채점·수정치 탐지. 브라우저와 Node 공용
assets/app.js       업로드, 기록 저장, 화면 그리기
assets/seed.js      기본 기록 (파서가 읽은 원본 숫자)
assets/style.css    스타일 (라이트/다크 모드)
```

외부 라이브러리는 CDN에서 불러옵니다: pdf.js 3.11.174(cdnjs), Chart.js 4.4.1(jsDelivr), Pretendard·Noto Serif KR 폰트.

## GitHub Pages 배포

압축을 풀고 폴더 **안의 내용물**을 저장소 최상위에 올린 뒤, Settings → Pages에서 `main` / `/ (root)`를 지정합니다. `index.html`이 저장소 첫 화면에 보여야 합니다.

## 계산 방법

- **조업일수**: 보도자료의 수출액 ÷ 일평균 수출액, 0.5일 단위 반올림
- **일평균 환산 증감률**: (1 + 증감률) × 전년 조업일 ÷ 올해 조업일 − 1
- **가격·물량 기여도**: (1 + 금액) = (1 + 단가)(1 + 물량)을 로그로 나눠 가격 몫(%p)과 물량 몫(%p)으로 분해. 물량 자료가 없는 반도체는 같은 달 생산지수로 대신합니다
- **흐름 판정**: 범주별 대표 신호의 부호를 수출(일평균 환산)과 비교. ±2% 이내는 보합으로 제외하고, 같은 부호 비율 100%면 ‘같은 방향’, 60% 이상 ‘대체로 같은 방향’, 그 미만 ‘엇갈림’. 재고 부담 = 재고 증가율 − 출하 증가율
- **체크리스트 채점**: 지난 기록에 저장된 지표 값과 이번 값을 비교해 목표 도달은 해소, 개선은 부분, 변화 없음은 지속, 나빠짐은 악화
- **수정치 탐지**: 지난 기록의 당월 값과 이번 보도자료의 전월 값을 비교해 0.1 이상 다르면 표시

## 주의

- 보도자료 서식이 바뀌면 일부 값을 읽지 못할 수 있습니다. 그때는 업로드 화면과 ‘유의사항’에 읽기 경고가 표시됩니다.
- 판정과 설명 문장은 숫자로 자동 생성한 참고 자료입니다. 중요한 수치는 원문 PDF와 대조하세요.
