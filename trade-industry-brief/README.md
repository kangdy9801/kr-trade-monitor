# 수출입·산업활동 브리핑

산업통상부 「수출입 동향」과 국가데이터처 「산업활동동향」 보도자료를 매달 쌓아 가며 읽는 정적 웹사이트입니다.
수출입은 당월, 산업활동은 한 달 전 자료가 같은 시기에 나오므로 둘을 한 묶음(기간)으로 기록합니다.

| 기간 파일 | 수출입 동향 | 산업활동동향 |
| --- | --- | --- |
| `assets/periods/2026-09.js` | 2026년 9월 (10.1. 배포) | 2026년 8월 (9.30. 배포) |
| `assets/periods/2026-10.js` | 2026년 10월 (11.1. 배포) | 2026년 9월 (10.30. 배포) |

상단 ‘기준 자료’에서 기간을 바꾸면 그때 화면을 그대로 볼 수 있습니다. 주소로는 `?p=2026-09`처럼 고릅니다. 아무것도 고르지 않으면 최신 기간이 열립니다.

## 다음 달 자료를 넣는 방법

1. 가장 최근 기간 파일을 복사해 새 파일을 만듭니다. 예: `assets/periods/2026-11.js`
2. 첫 줄의 키와 `id`를 새 기간으로 바꿉니다. `(window.PERIODS = window.PERIODS || {})["2026-11"]`
3. 새 보도자료 숫자로 내용을 바꿉니다.
   - `labels`, `meta`, `hero`, `texts`, `takeaways`: 화면 문구
   - `workdays`: 당월 조업일수(전년 → 올해)와 사유, 산업활동 기준월 전년 수출액
   - `months`, `trade`: 13개월 시계열, 수입, 지역
   - `industry`, `industryRows`: 산업활동 지표와 업종별 생산·출하·재고
   - `holidays`, `holidayNames`: 달력에 쓰는 공휴일 (새 달 추가)
   - `sectors`, `prices`, `decomposition`, `alignment`: 분야별 내용, 가격, 분해, 흐름 신호
4. **지난번 체크 결과**를 `followups`에 적습니다. `prevId`는 직전 기간 파일의 `checklist` 항목 `id`이고, `status`는 `해소`·`부분`·`지속`·`악화` 중 하나입니다.
5. 새 보도자료에서 바뀐 지난 수치를 `revisions`에 적습니다.
6. 다음 달에 확인할 항목을 `checklist`에 적고, 다음 발표 일정을 `nextReleases`에 적습니다.
7. `index.html` 아래쪽에 스크립트 한 줄을 추가합니다.
   ```html
   <script src="assets/periods/2026-11.js"></script>
   ```

`decomposition`의 `key`와 `alignment`의 분야 id는 기간끼리 같아야 ‘지난 자료 대비’ 비교가 연결됩니다.

## 계산 방법

- **조업일수**: 평일 1일, 토요일 0.5일, 일요일·공휴일 0일. ’25.9 24일, ’26.9 21.5일, ’25.10 20일, ’26.10 22일 모두 보도자료와 일치합니다.
- **일평균 환산 수출 증감률**: (1 + 증감률) × 전년 조업일 ÷ 올해 조업일 − 1
- **가격·물량 기여도**: (1 + 금액) = (1 + 단가)(1 + 물량)을 로그로 나눠 금액 증가율을 가격 몫(%p)과 물량 몫(%p)으로 분해합니다. 둘을 더하면 금액 증가율과 같습니다.
- **흐름 판정**: 분야마다 범주별 대표 신호(수출, 가격·단가, 물량·생산, 출하·판매, 재고 부담, 투자·수주)의 부호를 매깁니다. ±2% 이내는 보합으로 빼고, 수출과 같은 부호인 신호 비율이 100%면 ‘같은 방향’, 60% 이상이면 ‘대체로 같은 방향’, 그 미만이면 ‘엇갈림’입니다. 재고 부담 = 재고 증가율 − 출하 증가율.
- **판정 변화**: 엇갈림 → 대체로 같은 방향 → 같은 방향으로 오르면 ‘개선’, 내리면 ‘약화’입니다.
